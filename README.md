# 마음 한 조각

감정을 고르고 짧은 글을 남기는 한국어 감정 기록 웹사이트입니다. HTML/CSS/JavaScript만 사용하며 패키지 설치, 회원가입, API 키가 필요 없습니다.

## 바로 실행하기

`index.html`을 브라우저로 열면 됩니다. 기록은 사용 중인 브라우저의 localStorage에 저장됩니다.

개발할 때는 저장소 폴더에서 다음 명령으로 실행하는 것을 권장합니다.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

로컬 컴퓨터에서는 브라우저로 `http://localhost:8000`을 엽니다. 종료하려면 터미널에서 Ctrl+C를 누릅니다. 파일로 직접 열었을 때의 저장소 동작은 브라우저마다 다를 수 있으므로, 계속 사용할 때는 같은 주소에서 접속하세요.

## 기능

- 여섯 가지 감정 선택과 최대 300자 메모
- 최신순 기록 모아보기와 감정별 필터
- 확인 후 개별 기록 삭제
- 모바일 화면 대응, 키보드 조작, 저장 실패 안내

## 데이터 안내

서버로 기록을 전송하지 않습니다. 같은 브라우저와 같은 사이트 주소에서만 기록을 볼 수 있으며, 다른 기기와 동기화되지 않습니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 공용 컴퓨터에서는 다른 사용자가 기록을 볼 수 있으니 주의하세요.

## 개발 및 검증

- `index.html`: 화면 구조
- `styles.css`: 반응형 디자인
- `app.js`: 기록 저장, 표시, 필터, 삭제
- `node --test tests/*.test.cjs`: 저장 데이터 유효성 검사 테스트
- `node --check app.js`: JavaScript 문법 검사

정적 파일 서버나 GitHub Pages에 그대로 배포할 수 있습니다.
